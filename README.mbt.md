# FlowLabLite (MoonBit)

FlowLabLite is a lightweight, AI-native CFD solver for 2D lid-driven cavity flow,
written in [MoonBit](https://www.moonbitlang.com/) and compiled to WebAssembly.

See [README.md](README.md) for the full documentation: build steps, test suite,
validation data and the paper's release structure.
